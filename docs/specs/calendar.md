# カレンダーと記録の編集

目標は「いつ、どの部位を鍛えたかが一目でわかること」と、保存した記録をあとから見る・直す・消すことができること。

たたき台（Design キャンバス）: https://claude.ai/artifact/NZtuYkpJq6LfLeqrG5ZTP4

## 流れ

1. カレンダータブ → 月の表。日付をタップすると、下にその日の記録が出る
2. 記録をタップ → 記録の詳細（時間・長さ・種目ごとのセット）
3. 詳細の「編集」→ 記録を編集する画面（全画面のモーダル）→「保存」で反映 /「キャンセル」で何も変えない
4. 削除は、詳細の「この記録を削除」か、カレンダーの記録の行のスワイプ。どちらもアラートで確認する

## 部位ごとの色分け

日付のマスに、その日に鍛えた部位の色の点を付ける。1日に複数の部位をやった日は、点が複数並ぶ（同じ部位は1つにまとめる）。月の表の下に凡例を出す。

| 部位 | 色 |
|---|---|
| 胸 | 赤 |
| 背中 | 青 |
| 脚 | 緑 |
| 肩 | オレンジ |
| 腕 | 紫 |
| 腹筋 | 青緑 |

- 部位は種目の部位（`Exercise.bodyPart`）から決める。保存した記録には回数を入力したセットしか残らないので、実際にやった種目の部位だけが出る
- 今は部位と色を固定にしている。PUSH / PULL や全身法など、分け方を切り替える機能と、部位や色をユーザーが変える機能は今後追加する
- 腹筋を部位に足したのに合わせて、種目のプリセットにクランチとレッグレイズを加えた
- 色だけで見分けなくて済むよう、記録の行と詳細には部位の名前も出す。VoiceOver では日付のマスで部位の名前を読み上げる

## 月の表

- 日曜始まり。日曜は赤、土曜は青、未来の日付は薄く表示する
- 選んでいる日は塗りつぶしの丸、今日は枠線の丸
- 月の名前の下に、その月にトレーニングした回数を出す
- 月を移ると、今月なら今日を、それ以外の月なら1日を選ぶ
- 時刻は端末の言語設定によらず24時間表記（「19:02〜20:10」）

## 記録の編集

- 記録画面と同じく、種目一覧から種目ごとの入力ページに進む形にした。入力ページは記録画面のものをそのまま使う
- 元の記録の写しを編集し、「保存」を押したときだけ反映する。キャンセルすれば何も変わらない
- 開始日時を変えると、長さが変わらないよう終了日時も同じだけずらす。終了日時は開始日時より前にできない
- 保存するときは記録画面と同じく、回数を入力したセットだけを残す。回数を入力したセットが1つもなければ保存できない（消したいときは削除を使う）
- 入力ページの「前回」には、編集している記録より前に始めたトレーニングだけを使う。記録自身や、それより後のトレーニングが前回として出ないようにするため
- 開始日時を変えたら、履歴を開始日時の新しい順に並べ直す（「前回」を探すときに新しい順を前提にしているため）

## 保存

- 履歴は `@Shared(.workoutHistory)`（`IdentifiedArrayOf<Workout>`、開始日時の新しい順）。端末内の JSON ファイルに保存している
- サーバーへの保存は今後（フレンド機能を作るときに必要になる）
