# マイページの分析（1RM）

目標は「種目ごとに、最大挙上重量（1RM）がどう伸びているかを一目で振り返れること」。

## 流れ

1. マイページ → 「分析」ボタン → 種目一覧（push）が開く。記録画面の「種目を追加」に似た見た目（`StatsExerciseListFeature`）で、検索・部位チップで絞り込める。分析用の一覧なので「前回」のセット内容は出さず、種目名と部位だけを表示する
2. 種目をタップ → その種目の分析画面（push）が開く。種目名は大きく表示し、その下に全期間を通した自己ベスト（推定1RM）を出す
3. 期間（1ヶ月/3ヶ月/6ヶ月/1年/全期間）はセグメントで選ぶ
4. グラフの点をタップ、または左右にスワイプすると期間を選べる。選ぶと、その期間で一番強かったセット（重量×回数）と推定1RMを下に表示する
5. 別の種目を見るときは戻って種目一覧から選び直す

## 1RMの算出

- 1RM（1回だけ挙げられる最大重量）はEpley式で推定する: `1RM = 重量 × (1 + 回数 ÷ 30)`
- 重量・回数のどちらかが未入力のセットは対象外（`WorkoutSet.isRecorded` と同じ考え方だが、1RMには重量も必須）
- 区間（週・月など）の値は、その区間内にやった対象種目の全セットのうち、推定1RMが一番高いセットを採用する。同じ区間に複数回トレーニングしていても、ベストな1本だけを見る
- 画面上の表記は「1RM」ではなく常に「推定1RM」で統一する（実測値ではなく式による推定のため）
- 「自己ベスト」は選んでいる期間に関係なく、全期間（`.all`）での推定1RMの最高値。画面を開いた直後から、期間を選ばなくても見える
- 「1ヶ月」などの期間は、実際の今日からではなく、その種目を最後にやった日から遡って数える（`latestRecordDate`）。しばらく記録していない種目だと、今日から数えても直近の記録が入らないため

## 種目一覧

- `Exercise.presets`全種目を対象にする（記録の有無は問わない）。記録のない種目を選んでもグラフは空になるだけ
- 検索・部位チップでの絞り込みは記録画面の「種目を追加」（`ExercisePickerFeature`）と同じロジック。ただしこちらは一覧画面そのもの（push）で、選ぶと閉じるのではなく分析画面に進む。「前回」のセット内容はここでは出さない（記録を追加する場面ではないため）
- 部位ごとの集計（回数・ボリューム・セット数）は分析画面には出さない。1RMは種目に対する値で、部位に集約する意味がないため

## 推移グラフ

- 棒の単位・本数はカレンダー分析で使っていたものをそのまま流用（`TrendRange`）: 1ヶ月=週ごと4本、3ヶ月=月ごと3本、6ヶ月=月ごと6本、1年=月ごと12本、全期間=区切りなし1本
- 見た目・操作（タップで選択、スワイプで期間移動、矢印での期間送り）は部位分析のときと同じ`TrendLineChart`をそのまま使う
- グラフの下に、表示している区間での伸びをkgと%で出す（例: 「+15.0kg（+12.1%）」）。記録がある点の最初と最後を比べる（空の区間は無視する）。プラスは緑、マイナスは赤。記録がある点が1つ以下なら出さない
