# アプリ全体の構成

## 目指すもの

自分の筋トレを記録しつつ、フレンドが今トレーニングしているか（「OREN がトレ中」「SOGO が5分前にトレ」）や、フレンドの記録をタイムラインで見られるアプリ。フレンド機能にはいずれサーバーが必要になるが、今は端末内に保存している。

## タブ

| タブ | 内容 |
|---|---|
| ホーム | 上部にフレンドのトレーニング状況、その下にタイムライン（未実装） |
| カレンダー | 過去のトレーニング履歴（未実装） |
| マイページ | 自分のプロフィールや集計（未実装）。タブが2つだと寂しいので追加した |
| ＋（記録） | タブではなく、記録画面を全画面のモーダルで開くボタン |

- 設定画面の置き場所は未定（ホームの右上か、マイページか）
- 対象は iOS 26.1 以上に絞った。iOS 25 以下を切り捨てることで、自作のタブバーと OS ごとの出し分けが不要になり、Liquid Glass の標準タブバーをそのまま使える。26.1 なのは `tabViewBottomAccessory(isEnabled:)` を使うため

## ＋ボタンを他のタブと違う見た目にしている理由

記録は「タブを切り替える」のではなく「モーダルで画面ごと切り替わる」ため。タブを押しただけでタブバーごと消える体験は良くないので、他のタブとは違う動きをすることを見た目で先に知らせる。

- 当初はタブバー中央から飛び出す＋ボタンを考えたが、Liquid Glass の標準タブバーでは作れない。自作すると Liquid Glass の見た目や動きを作り直すことになる
- そこで `Tab(role: .search)` を使い、タブバーの右に独立した丸いボタンとして表示している（MyFitnessPal の iOS 26 版と同じ配置）。位置はシステムが決めるので右固定
- 記録画面は `.fullScreenCover` で開く

## 記録中の最小化

記録画面は左上のボタンで最小化できる。最小化中はタブバーの上（`tabViewBottomAccessory`）に経過時間と今の種目を表示し、タップで記録画面に戻る。トレーニングの途中でカレンダーを見たい、といった場面のため。
